# 🗂 Docs

Only what spans more than one project lives here. A project's own reference stays in its
`README.md` and `CLAUDE.md` ([0001](./decisions/0001-feature-discoverability.md)). The developer
portal renders these files too, so links must work on GitHub and there.

| Folder | Holds |
| --- | --- |
| [`FEATURES.md`](./FEATURES.md) | Generated index of every command, hook, workflow and skill, with the doc that explains it |
| [`concepts/`](./concepts/README.md) | Cross-project models: the *why*, no procedure |
| [`guides/`](./guides/README.md) | Cross-project step-by-step tasks |
| [`decisions/`](./decisions/README.md) | Architectural decisions, one per spike |
| [`audits/`](./audits/README.md) | Dated findings lists for one project, worked down one by one |
| [`benchmarks/`](./benchmarks/README.md) | Sites analysed as design references, one file per site |
| [`workflows/`](./workflows/README.md) | The rules for multi-ticket projects tracked on the portal |
